# save-editors

Editors and patchers for game save files.

## Games

| Folder | Game | Notes |
|---|---|---|
| [`cell-to-singularity/`](./cell-to-singularity/) | Cell to Singularity — Evolution Never Ends | Edits in-game currencies in the local save. |

## General warnings

- **Back up your save folder** before running anything.
- Editing a save can get your account flagged as a cheater if the game validates
  progress server-side. Check the per-game README.
- Close the game before editing, or it may overwrite your changes on exit.
