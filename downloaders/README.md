# downloaders

Scripts that pull files down from a site or service.

## Tools

| Folder | Source | Notes |
|---|---|---|
| [`khinsider/`](./khinsider/) | [downloads.khinsider.com](https://downloads.khinsider.com) | Downloads a full game-soundtrack album (mp3/flac) + cover, and tags track numbers. |

## General notes

- Be reasonable about request rate - every tool here leaves a small delay between
  requests by default; don't crank it to zero on someone else's server.
- Grab things you have a right to grab. These are personal convenience tools.
